## 版本与去重说明

- **录音室专辑**：Transmissions (2014)、Vessels (2017)、DIVISIONS (2019)、HORIZONS (2021)、SILOS (2025)。
- **Deluxe / 2.0**：Transmissions (Deluxe Edition) 与 Vessels 2.0 文件夹只放新增的 acoustic / remix / 重录版本；原版曲目已在对应专辑文件夹中，不重复。
- **早期版本**：The Prox Transmissions EP 中的《Carnivore》《My Demons》是 2013 年早期录音，和 2014 专辑版长度不同，单独保存。
- **地区限定**：日本版《Vessels》追加的《Monster (feat. HYDE)》单独放在 `Vessels (Japanese Version)` 文件夹。
- **同名多版本**：acoustic、remix、re-recorded、reimagined 版本均单独成文件，并在文件开头注明与原生版本的关系。
- **纯音乐**：The Order、UNVEILING THE ARCHITECTURE、praesens 等间奏曲保留占位文件，标注为 instrumental。
- **翻唱**：Kashmir (Led Zeppelin)、Space Oddity (David Bowie)、Love You to Death (Type O Negative)、Shattered Dreams (Johnny Hates Jazz)、Head Over Heels (Tears for Fears)。
- **未重复收录**：Daytrotter Session 中的 Antigravity / Halo / My Demons 现场版与专辑版歌词相同，未单独复制；Starset (Remixes) EP 的两首混音已并入 Transmissions (Deluxe Edition)。
- **2026 单曲**：截至 2026-10-30，WE ARE EMPIRE、p a r a d 0 x 1 c、a n n 1 h 1 l a t 1 0 n、t r a n s f u s 1 0 n 均以单曲形式发行，尚未对应新的录音室专辑；其中 WE ARE EMPIRE 为游戏《Arknights: Endfield》单曲。
